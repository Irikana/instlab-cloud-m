# v0.0.11 — 作业纸按电脑版实测值对齐，课程表上线

**构建日期：** 2026-09-20

## 修复

- **作业纸身份条码尺寸与位置**：按电脑版真实生成的 PDF 量出准确数值后重做。条码在纸面上是 65.0x21.5mm，其中竖条 17.15mm、下方可读数字 9.35pt；位置是右边缘距页面右边 15mm、顶边距页顶 15mm，也就是落在上边距带里，而不是此前估计的 65x10.6mm、距顶 10mm。
- **抬头图把整页正文顶偏**：电脑版的学习通标识同样是压在页眉带里的（60.8x18.5mm，左 15mm、距顶 15mm），正文从距顶 30mm 起排。手机端此前把标识插进正文流里，于是整页内容比电脑版低了一整条标识的高度。现在标识与条码都按页盖章，正文起点与电脑版一致。
- **分页规则与电脑版不一致**：电脑版的出图引擎按行连续断页，手机端此前只在顶层大块之间断页，一道大题塞不进当页剩余空间时整块挪到下一页，页底留出一大段空白、断点也对不上。现在允许向下拆一层，并按同一页内相邻同源片段合并回同一个外层标签（表格不会被拆成两张，边框与行距才不会走样）。
- **条码缺失的成因与兜底**：作业 ID 取不到时整份文档不再有条码。现在按几个常见字段名依次查找，并在预览页底部标注这次是从哪个字段取到的；确实取不到时不画条码，宁缺勿错——错号的作业纸会被机器判到别人名下。
- **导出文件名与电脑版统一**：日期部分改为「2026年9月8日_(星期二)」写法，与电脑版生成的文件名一致（此前手机端压成 20260908）。

## 新增

- **课程表**：首页「课程表」入口正式可用。按星期排列所选学期的实验、理论课与值日安排，同一门课每周重复出现的合并成一条；学期切换与作业纸页共用同一个选择，两边保持一致。

## 说明

- 中文宋体仍与电脑版不同（电脑版把字体装进系统供出图程序取用，Android 没有等价条件），公式部分已内置同款样式与字体。
- 实验报告的提交与批改后答题纸图片的下载，需要服务器文件接口的实际参数才能接通；电脑版这两个动作与作业纸同为日程条目上的不同按钮，手机端也放在同一个条目里，不会拆成两处。

## 验证

- `pc-analysis/check-paper-pipeline.js` 扩到 51 项断言，其中新增的一组直接以电脑版真实 PDF 量出的数值为准绳：版心 679x934 CSS px、页边距 30/20/15/15mm、条码 65.0x21.5mm 与 17.15mm 竖条、抬头图 15mm/15mm、条码解码内容 08+页码+ID 补零 9 位、文件名写法。
- 新增分页算法断言：可拆/不可拆/单子块不拆/拆分后合并外壳/内容不丢/空文档仍出一页。
- `pc-analysis/simulate-release-gate.js`：用桩 gh 与 git 实跑发布判定的四种触发路径。
- 发布判据由「远端有没有 tag」改为「有没有 Release」，并支持三种触发：推 tag、手动指定 tag（补发历史版本时用）、以及推送到 main 时按版本号自动发布已发布过的版本不再覆盖。
