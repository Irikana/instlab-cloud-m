# v0.0.3 — 作业纸 PDF 下载 + 日历日程视图 + 首页问候

**构建日期：** 2026-08-04

## 新增功能

- **日历日程视图**：在「下载作业纸」页面加入月份日历组件，日历上自动标记有实验/理论课/值日的日期
- **按日期查看安排**：选中日期后显示该日完整日程（实验序号、名称、时间、地点、教师）
- **作业纸 PDF 下载**：点击日程条目上的「下载空白作业纸」或「批改后」按钮，自动调用 `/api/paper/work` API 并生成 PDF 文件（expo-print），通过系统分享面板保存
- **实验 ID 测试模式**：保留通过 schid 直接下载作业纸的入口（tab 切换），供验证 API 猜想
- **首页问候**：登录后首页显示「你好，XXX同学」个性化问候（含头像首字缩写）
- **API 工具模块**：创建 `src/lib/api.ts`（统一 fetch + cookie 封装）、`src/lib/schedule.ts`（学期+日程 API）、`src/lib/paper.ts`（作业纸下载+PDF 生成管线）

## 变更

- 版本号 0.0.2 → 0.0.3
- 移除所有 UI 页面中的 emoji 图标，改用纯文字标识
- 首页状态栏改为问候卡片样式（头像缩写 + 姓名 + 学号）

## 依赖变更

- 新增 `expo-print ~57.0.1`（HTML→PDF 生成）
- 新增 `expo-sharing ~57.0.8`（PDF 分享/保存）
- 上述依赖通过 `expo install` 安装，CI 的 `expo prebuild` 会自动生成原生工程配置
