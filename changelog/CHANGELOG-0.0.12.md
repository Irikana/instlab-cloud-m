# v0.0.12 — 抬头图/条码/页码恢复显示，课程表补全教室与周次

**构建日期：** 2026-09-21

## 修复

- **抬头图、条码、码下数字、页数提示一并消失**：两处独立原因叠加。其一是分页脚本要搬进测量 WebView 执行，此前按名逐个搬函数，算法内部调用的一个私有辅助函数没被一起搬过去；其二是脚本用"注入"方式在文档解析完成前就执行，量到空的正文。两者都会让回传永远不发生、界面安静地卡在测量阶段，而这几个元素全部由分页完成后的拼版盖章。现在算法收进一个自包含函数、注入改到文档加载完成后触发、正文未就绪时自动重试，并加了一条超时兜底。
- **测量失败时不再静默卡住**：万一还是没有回传，12 秒后自动退回连续文档并写明原因，而不是让你对着一张不动的预览猜。
- **超过一页高度的题目被裁切**：整块挪页时，比一页还高的块会被页面容器直接裁掉，内容凭空少一截。现在一路向下拆到装得下为止（真实作业纸是 表格 > 表体 > 行 > 单元格 的层层嵌套，中间每层往往只有一个孩子，所以单子块也要继续下钻），并把同一页内同源的相邻片段并回同一个外壳，表格不会被拆成两张。
- **课程表的课程一律显示成"实验"**：日程条目里其实没有任何类型字段，实验与理论课的区分只存在于它是哪个接口返回的。此前没记录来源，全部落到默认分支判成实验，因此蓝色标注永远出不来。现在按来源接口定类型。
- **周次取不到学期起始日**：服务器给的字段是 `date_start` / `date_end`，此前的候选名没覆盖到，导致周次一律留空。
- **签到与实验序号字段名**：真实响应里是 `signin_time` / `signined` 与 `expnumber`，此前只认 `time_signin` / `expno`，这两项因此不显示。
- **APK 之间无法区分版本**：出图流程生成的工程里 versionCode 恒为 1，任何两个 APK 在 Android 看来都是同一版本，装上新的会被视为覆盖甚至被拒，也分不清装到的到底是哪一次构建。现在构建时按运行次数注入 versionCode，测试构建的版本号同时带上构建号。

## 新增

- **课程表区分课程与实验**：理论课（含其作业）整行改用蓝色标注——左侧色条、类型徽标、标题同色；实验与值日仍为橙色，两类事情在颜色上一眼分开。
- **课程表显示教室**：教室单独成行，数据没给时留空而不是和节次挤在一起。
- **课程表显示周次**：优先用服务器给的周次字段；没有时按学期起始日推算（对齐到日历周，学期中间开课不会少算一周），连续区间显示为"第3-12周"，断开则列举。推不出时不显示周次，不编一个数。
- **日程数据导出**：开发者模式下作业纸页新增"日程JSON"按钮，导出学期对象与日程条目的原始字段，用于确认教室、周次这些字段服务器到底放在哪儿。

## 说明

- 中文宋体本轮仍未内置：本机拿不到能压缩 CFF 轮廓的工具链（subset-font 对 CFF 直接跳过压缩，fonteditor-core 无法解析 CFF，Google Fonts 在当前网络下不可达），只能产出每个字重 2.56MB 的原始子集、以 data URI 注入约 3.4MB——这份体积要进每一份打印文档。电脑版之所以"PDF 只有几百 KB"，是它的出图引擎把字体裁剪后嵌进了 PDF 成品，与我们要在输入侧塞整份字体不是同一件事。要补需要装 Python 的 fonttools（pyftsubset）来产出真正的 woff2 子集。
- 分页落点仍受字体影响：真实作业纸正文量到 938 CSS px，而一页版心是 933.5px，只差 4.5px。电脑版用宋体排版行高更大、断点更靠前，因此在宋体内置之前，页数与断点仍可能与电脑版差一页。
- 周次能否显示取决于服务器是否给学期起止日期或周次字段；真实学期给了 `date_start`（2026-09-07）与 `date_end`，据此可推出本学期跨到第 18 周左右。
- 实验报告的提交与批改后答题纸图片的下载仍未接通：真实响应里 `corrlist` 在未批改时是空数组，看不到图片引用的形状，需要一份已批改作业的 JSON 才能确定字段。
