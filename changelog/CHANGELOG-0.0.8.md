# v0.0.8 — 作业纸底版背景 + 文件名规范 + 二维码

**构建日期：** 2026-08-04

## 作业纸生成重构

- **底版背景嵌入**：`buildFullHtml` 将服务器返回的 `titlelogo`（base64 PNG，2937x893 像素的完整作业纸底版图，含预印刷表格/定位标记/学校标识）作为 HTML body 的 CSS 背景，与 PC 端 C# 做法一致
- **日期填充**：用服务器返回的 `sch_datestring`（PC 端格式，如 `2026年3月4日 (星期三) (节)`）替换 HTML 模板中的硬编码下载当天日期
- **班级/学号/姓名**：服务器通过登录 cookie 已在 HTML 中填入（不再需要 App 侧二次填充）
- **二维码**：HTML 模板中的 DataMatrix 脚本 + `.svgdiv` 元素会自动在每道题肩头生成 SVG 二维码（编码题目 ID），与 PC 端 wkhtmltopdf 渲染一致

## 文件名规范

- PDF/HTML 文件名改为 PC 端标准格式：`课程作业纸_{课程名称}_{学号}_{姓名}_{日期}.pdf`
- 批改版：`批改作业纸_{课程名称}_{学号}_{姓名}_{日期}.pdf`

## 关于「作业纸与 PC 端一致性」的结论

**手机端与 PC 端使用完全相同的输入数据**（同一 `{html, data, titlelogo}`），差异仅在于渲染引擎（expo-print vs wkhtmltopdf）。字体栈已添加 fallback 保证中文字体显示一致。`titlelogo` 底版图确保定位二维码/条形码标记与 PC 端相同。批改作业纸无法显示手写笔迹/评分——这是批改后扫描件，PC 端显示的也是扫描图片，手机端暂不支持。
