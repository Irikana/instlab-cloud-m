INSTLAB CLOUD M
移动端教学管理 · 智慧教学助手

简介

INSTLAB CLOUD M 是基于 cloud.instlab.cn 服务开发的移动端教学管理 App（Android），支持登录后查看实验安排、下载作业纸 PDF 等。

当前版本：v0.0.4
通过下方按钮下载安装包（APK）。安装前请允许安装未知来源应用。

功能

登录：学号/工号 + 密码 + 验证码 + 学校代码，与 PC 端一致。

日历日程：按日期查看实验/理论课/值日安排，日历标注配色与 PC 端一致（实验橙、作业蓝）。

作业纸下载：一键下载空白作业纸 / 批改后作业纸 PDF，支持下载原始 HTML 排错。

主题：Cloud Lite（#00695C）/ Quasar / 深色等多套主题。

更新检查：App 内直接检查最新版本并下载。
